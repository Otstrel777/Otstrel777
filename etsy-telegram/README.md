# Заказы Etsy → Telegram

Скрипт Google Apps Script, который работает во **второй почте**. Каждые 5 минут он ищет
письма «You made a sale on Etsy» и отправляет заказ в группу Telegram. Ваш компьютер для этого не нужен.

Как устроено:
Etsy → основная почта → (фильтр Gmail) → вторая почта → скрипт → группа Telegram

## Пример сообщения в группе

```
1086) 🛍 Новый заказ #4236106400
📦 Отправить до: 25 ноя

1. Pastel Striped Vinyl Stickers: IKEA TROFAST Bin Decals × 1
   • Size: Small
   • Color: 4 - Sage Green
   €8,00

👤 Имя покупателя
📍 Адрес доставки

💰 €21,90 · доставка €8,90 · скидка −€7,00 (35OFFSTORAGE)
```

**Нумерация.** Каждый заказ получает сквозной номер: `1086)`, `1087)` и так далее.
Номер привязан к заказу: при повторной отправке (`testLastOrder`) он не меняется.
Начальный номер задаётся в начале скрипта (`START_NUMBER`). Если нужно сдвинуть счётчик,
впишите следующий номер в свойство скрипта `NEXT_ORDER_NUMBER`.

**Сумма** показывается с разбивкой, как в письме: товары, скидка (с промокодом), подытог,
доставка, налог и итог. Нулевые скидка и налог не показываются.

**Налоговый номер для посылки.** Если Etsy собрал налог и просит указать свой номер
(UK VAT, норвежский VOEC и т. п.), в сообщении появится блок «📮 Налог для посылки»
с номером и, для Великобритании, стоимостью заказа в фунтах.

**Без дублей.** Каждый заказ отправляется в группу один раз, даже если запуск скрипта
оборвался посередине. `testLastOrder` присылает заказ с пометкой «🔁 Повторная отправка (тест)».

Персонализация выделяется отдельно (✏️), а количество больше 1 — значком ‼️.

**Фото товара.** Сообщение приходит с фото товара, а текст заказа — подписью под ним.
Скрипт берёт фото из письма и старается загрузить версию 570 px. Если не получится,
берёт миниатюру из письма. Если товаров с разными фото несколько, они придут альбомом.
Если фото не загрузится совсем, заказ всё равно придёт текстом.

## Свои фото из таблицы

К фото из письма можно добавить свои фото листинга из Google-таблицы.

1. Запустите функцию `createPhotoSheet`. Она создаст во второй почте таблицу «Etsy — фото листингов»
   и впишет в колонку A заголовки из уже пришедших заказов. Ссылка на таблицу будет в журнале.
2. В колонку A допишите заголовки остальных листингов — **точно как в Etsy**.
   Новые заголовки из заказов скрипт дописывает в таблицу сам, если их там ещё нет.
3. В колонки «Фото 1», «Фото 2»… вставьте фото одним из способов:
   - **ссылка с Google Диска (лучше всего):** загрузите фото на Диск второй почты →
     правой кнопкой → «Поделиться» → «Копировать ссылку» → вставьте в ячейку;
     Формат — **JPG или PNG** до 10 МБ. HEIC с iPhone Telegram не принимает: в Фото на Mac
     «Файл» → «Экспортировать» → JPEG;
   - прямая ссылка на картинку (`https://….jpg`);
   - формула `=IMAGE("https://….jpg")`;
   - картинка, вставленная в ячейку («Вставка» → «Изображение» → «В ячейку»).
4. Ничего запускать не нужно: со следующего заказа фото из таблицы придут вместе с фото из письма.

- Фото из таблицы идут **после** фото из письма. Чтобы показывать **только** фото из таблицы,
  в начале скрипта поменяйте `SHEET_PHOTOS = 'add'` на `'replace'`
  (если для листинга фото в таблице нет, возьмётся фото из письма).
- В одном сообщении Telegram — не больше 10 фото, лишние не отправятся.
- Заголовок в таблице можно сократить: достаточно начала заголовка (от 15 символов).

## Сводка по срокам отправки

Отправленный заказ отмечайте в группе реакцией 👍 на сообщение с заказом (на любое фото альбома).
Каждый день в 9:00 (по часовому поясу проекта Apps Script) бот присылает сводку:

```
⏰ Сводка по отправке — 26 ноя

🔴 Просрочены (2):
• 1087) #4234835543 — до 24 ноя, просрочен на 2 дн.
• 1086) #4236106400 — до 25 ноя, просрочен на 1 дн.

🟡 Отправить сегодня (1):
• 1088) #4237000000
```

- Заказ считается просроченным со следующего дня после даты «Ship by», если на нём нет 👍.
- Если 👍 снять, заказ снова попадёт в сводку.
- **Бот должен быть администратором группы**, иначе Telegram не показывает ему реакции,
  и все заказы будут считаться неотправленными.
- Если группа превратилась в супергруппу (это бывает, когда бота делают админом), бот сам
  переключится на её новый id. Номера в сводке тогда станут ссылками на сообщения с заказом.
- Время сводки меняется в начале скрипта (`SUMMARY_HOUR`), после этого запустите `setup` ещё раз.
- `testSummary` присылает сводку сразу, для проверки.

## Настройка (около 10 минут, один раз)

### 1. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя и username (заканчивается на `bot`).
2. Сохраните токен (`123456789:AAH…`). Никому его не пересылайте.
3. Добавьте бота в рабочую группу и напишите там `/start@имя_бота`.

### 2. Скрипт
1. Войдите в **вторую почту** и откройте **https://script.google.com** → «Создать проект».
2. Назовите проект, например «Etsy → Telegram».
3. Удалите всё содержимое файла `Код.gs` и вставьте туда содержимое [`Code.gs`](Code.gs). Сохраните (💾).
4. Слева нажмите ⚙️ **«Настройки проекта»** → внизу **«Свойства скрипта»** → «Добавить свойство»:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — пока поставьте `0`, ниже узнаем
5. Вернитесь в редактор (`<>`), выберите вверху функцию **`getChatId`** и нажмите **«Выполнить»**.
   - Google попросит разрешения: «Проверить разрешения» → ваш аккаунт → «Дополнительно» →
     «Перейти к проекту (небезопасно)» → «Разрешить». Это ваш собственный скрипт.
   - В журнале появится строка `TELEGRAM_CHAT_ID = -100…`. Число вместе с минусом
     впишите в свойство `TELEGRAM_CHAT_ID`.
6. Выберите функцию **`setup`** → «Выполнить». В группу придёт «✅ Бот подключён».
7. Проверка: выберите функцию **`testLastOrder`** → «Выполнить». В группу придёт последний заказ.

После этого скрипт работает сам: каждый новый заказ появится в группе в течение ~5 минут.

## Что делают функции

| Функция | Зачем |
|---|---|
| `setup` | Разовая настройка: создаёт расписание и помечает старые письма, чтобы не слать их в группу |
| `checkNewOrders` | Запускается по расписанию, отправляет новые заказы |
| `testLastOrder` | Отправить последний заказ ещё раз (для проверки) |
| `dailySummary` | Запускается по расписанию раз в день, присылает сводку по просроченным заказам |
| `testSummary` | Прислать сводку прямо сейчас |
| `createPhotoSheet` | Создать таблицу «заголовок листинга → фото» |
| `getChatId` | Узнать id группы |

Отправленные письма получают метку **«Etsy/Отправлено в TG»**. Чтобы переотправить заказ,
снимите метку с письма.

## Доступы
- Скрипт читает только почту, в которой он создан (вторую), и ставит метки на письма.
- Бот может только отправлять сообщения в группу.
- Доступа к магазину Etsy нет ни у кого.

## Если что-то не работает
- **Ничего не приходит:** в редакторе откройте слева «Выполнения» (▶ с часами) и посмотрите ошибки.
- **`Telegram ответил 400: chat not found`:** неверный `TELEGRAM_CHAT_ID` или бот не в группе.
  Если группа стала «супергруппой», её id изменился — запустите `getChatId` снова.
- **`Telegram ответил 401`:** неверный токен бота.
- **Письма не доходят до второй почты:** проверьте фильтр пересылки в основной почте.
