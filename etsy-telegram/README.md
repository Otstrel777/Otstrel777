# Заказы Etsy → Telegram

Скрипт Google Apps Script, который работает во **второй почте**. Каждые 5 минут он ищет
письма «You made a sale on Etsy» и отправляет заказ в группу Telegram. Ваш компьютер для этого не нужен.

Как устроено:
Etsy → основная почта → (фильтр Gmail) → вторая почта → скрипт → группа Telegram

## Пример сообщения в группе

```
🛍 Новый заказ #4236106400
📦 Отправить до: 25 ноя

1. Pastel Striped Vinyl Stickers: IKEA TROFAST Bin Decals × 1
   • Size: Small
   • Color: 4 - Sage Green
   €8,00

👤 Имя покупателя
📍 Адрес доставки

💰 €21,90 · доставка €8,90 · скидка −€7,00 (35OFFSTORAGE)
```

Персонализация выделяется отдельно (✏️), а количество больше 1 — значком ‼️.

**Фото товара.** Сообщение приходит с фото товара, а текст заказа — подписью под ним.
Скрипт берёт фото из письма и старается загрузить версию 570 px. Если не получится,
берёт миниатюру из письма. Если товаров с разными фото несколько, они придут альбомом.
Если фото не загрузится совсем, заказ всё равно придёт текстом.

## Настройка (около 10 минут, один раз)

### 1. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя и username (заканчивается на `bot`).
2. Сохраните токен (`123456789:AAH…`). Никому его не пересылайте.
3. Добавьте бота в рабочую группу и напишите там `/start@имя_бота`.

### 2. Скрипт
1. Войдите в **вторую почту** и откройте **https://script.google.com** → «Создать проект».
2. Назовите проект, например «Etsy → Telegram».
3. Удалите всё содержимое файла `Код.gs` и вставьте туда содержимое [`Code.gs`](Code.gs). Сохраните (💾).
4. Слева нажмите ⚙️ **«Настройки проекта»** → внизу **«Свойства скрипта»** → «Добавить свойство»:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — пока поставьте `0`, ниже узнаем
5. Вернитесь в редактор (`<>`), выберите вверху функцию **`getChatId`** и нажмите **«Выполнить»**.
   - Google попросит разрешения: «Проверить разрешения» → ваш аккаунт → «Дополнительно» →
     «Перейти к проекту (небезопасно)» → «Разрешить». Это ваш собственный скрипт.
   - В журнале появится строка `TELEGRAM_CHAT_ID = -100…`. Число вместе с минусом
     впишите в свойство `TELEGRAM_CHAT_ID`.
6. Выберите функцию **`setup`** → «Выполнить». В группу придёт «✅ Бот подключён».
7. Проверка: выберите функцию **`testLastOrder`** → «Выполнить». В группу придёт последний заказ.

После этого скрипт работает сам: каждый новый заказ появится в группе в течение ~5 минут.

## Что делают функции

| Функция | Зачем |
|---|---|
| `setup` | Разовая настройка: создаёт расписание и помечает старые письма, чтобы не слать их в группу |
| `checkNewOrders` | Запускается по расписанию, отправляет новые заказы |
| `testLastOrder` | Отправить последний заказ ещё раз (для проверки) |
| `getChatId` | Узнать id группы |

Отправленные письма получают метку **«Etsy/Отправлено в TG»**. Чтобы переотправить заказ,
снимите метку с письма.

## Доступы
- Скрипт читает только почту, в которой он создан (вторую), и ставит метки на письма.
- Бот может только отправлять сообщения в группу.
- Доступа к магазину Etsy нет ни у кого.

## Если что-то не работает
- **Ничего не приходит:** в редакторе откройте слева «Выполнения» (▶ с часами) и посмотрите ошибки.
- **`Telegram ответил 400: chat not found`:** неверный `TELEGRAM_CHAT_ID` или бот не в группе.
  Если группа стала «супергруппой», её id изменился — запустите `getChatId` снова.
- **`Telegram ответил 401`:** неверный токен бота.
- **Письма не доходят до второй почты:** проверьте фильтр пересылки в основной почте.
